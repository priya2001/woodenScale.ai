# WoodenScale AI - Fundraising Platform

A premium SaaS platform powered by AI to help startups streamline their fundraising journey from ideation to investment.

## Features

- **AI-Powered Pitch Deck Builder** - Create investor-ready pitch decks in minutes
- **Smart Investor Matching** - Connect with investors who align with your startup
- **Automated Financial Projections** - Generate accurate financial models effortlessly
- **Intelligent Investor Outreach** - Personalized outreach campaigns with AI assistance
- **Expert Network Access** - Connect with experienced founders and fundraising experts

## Tech Stack

- **Frontend**: Next.js 16.1.2, React 19.2.3, TypeScript
- **Styling**: Tailwind CSS v3.4.19
- **UI Components**: Custom premium SaaS design system
- **Deployment**: Ready for Vercel/Netlify hosting

## Design Highlights

- Dark-themed premium SaaS interface
- Gold/yellow accent color scheme (#f5c96a primary, #f1ad3a secondary)
- Responsive design for all device sizes
- Smooth animations and transitions
- Professional investor-focused UI

## Getting Started

First, install dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
```

Then, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run start` - Start production server
- `npm run lint` - Run ESLint checks

## Responsive Design

The platform is fully responsive with breakpoints configured for:

- Mobile: 768×360 and below
- Tablet: 768×1024 to 1024×1366
- Desktop: 1024×768, 1280×800, and above
